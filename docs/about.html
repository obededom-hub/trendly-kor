소개

TRENDLY은 지금 한국에서 뜨는 주제 — 경제, IT, 라이프스타일, 문화 등을 모아 정보성 글로 정리하는 자동 발행 매체입니다.

모든 콘텐츠는 로컬에서 돌아가는 AI 모델(Qwen 언어모델, Flux 이미지 모델)이 실시간 트렌드를 분석해 작성합니다. 사람이 직접 작성한 뉴스가 아니라 AI가 선별·정리한 정보 요약임을 알립니다.

편집 원칙

  • 실제 검색 신호(뉴스·이슈)를 기반으로 주제만 선별합니다.
  • 단정적 숫자·일자는 과장하지 않는 선에서 정리합니다.
  • 독자의 검색 의도를 충족하는 실용·정보 중심 문체를 지향합니다.

콘텐츠 수정·제안이나 제휴 문의는 문의 페이지를 이용해 주세요.
